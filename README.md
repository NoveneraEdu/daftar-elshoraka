# دفتر الشركاء

تطبيق حسابات نوفينيرا وسنترا ونبض: المدرسين، الدخل، المصروفات والسلف، وأرصدة الشركاء.

- الواجهة: ملف `index.html` واحد، منشور على GitHub Pages.
- البيانات: Supabase (مشروع `daftar-elshoraka`)، محمية بتسجيل الدخول وصلاحيات RLS لإيميل صاحب الحساب فقط.
- المفتاح الموجود في الكود مفتاح عام (publishable) وآمن، الحماية الفعلية من سياسات RLS في قاعدة البيانات.
